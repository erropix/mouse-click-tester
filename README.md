# Mouse Click Tester

A simple web app to track and monitor mouse button events in real-time.

## Features

- **Event Counters**: Track mousedown, mouseup, click, and double-click events
- **Event Log**: View the last 10 events with timestamps
- **Color-Coded Display**: Each event type has its own color for easy identification
  - 🔴 Double Click (Red) - Perfect for detecting accidental double-clicks
  - 🟣 Click (Purple)
  - 🔵 Mousedown (Blue)
  - 🟢 Mouseup (Green)
- **Reset Functionality**: Clear all counters and event history with one click

## Usage

Simply open `index.html` in your web browser and start clicking in the interactive area.

## Live Demo

Visit the GitHub Pages deployment: [Mouse Click Tester](https://erropix.github.io/mouse-click-tester/)

## Use Case

Ideal for testing mouse hardware, checking for faulty switches that cause accidental double-clicks, or understanding mouse event sequences.
